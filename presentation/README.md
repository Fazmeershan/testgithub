# Dawodia Holding — Our Values deck

`Dawodia_Holding_Our_Values.pptx` is a 9-slide, 16:9 deck: a cover, the seven value slides and a closing slide. Each slide has speaker notes.

## Logo and colours

`assets/logo.png` is the Dawodia Holding round badge on a transparent background. It sits in the top-right corner of every slide.

The colours come from the logo: deep burgundy (`4A0F26`), crimson (`B8315A`) and silver (`D6D9DE`). They are set in the `C` object at the top of `build_deck.js`.

To rebuild the deck:

```bash
npm install pptxgenjs react react-dom react-icons sharp
node build_deck.js
```
